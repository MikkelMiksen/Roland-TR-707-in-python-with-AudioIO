# Recreation of the ROLAND TR-707 Drum Kit in Python using SoundDevice and NumPy

This project is a faithful recreation of the legendary Roland TR-707 drum machine, implemented in Python. By leveraging the capabilities of libraries like SoundDevice and NumPy, the project provides an educational and functional exploration of audio synthesis and drum machine emulation.

## Features
- **Drum Kit Sample Recreation**: Faithful emulation of the iconic TR-707 drum samples and rhythm patterns.
- **Python-based Audio Processing**: Makes use of the SoundDevice library for audio playback and NumPy for signal processing.
- **Customizable Patterns**: Create and modify drum patterns programmatically.
- **Cross-platform Compatibility**: Works on all platforms supported by Python and the required libraries.

## Getting Started
1. Clone the repository:
    ```bash
    git clone https://github.com/MikkelMiksen/Roland-TR-707-in-python-with-AudioIO.git
    ```
2. Install the required dependencies:
    ```bash
    pip install sounddevice numpy
    ```
3. Run the application:
    ```bash
    python main.py
    ```
